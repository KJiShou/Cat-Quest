## 本项目如何应用

| 读者问题 | README 处理 |
| --- | --- |
| 是什么，为什么使用 | 产品、受众与效率循环，不编造实验结论 |
| 实际有哪些功能 | 对照脚本、预制体、构建场景和现有文档，明确可选在线依赖 |
| 长什么样 | 真实渲染、演示数据与拍摄来源 |
| 如何开始 | 当前 Unity 版本、Bootstrap/CharacterHome、源码运行和 Windows 构建 |
| 为什么锁定 | 当前等级、Boss 条件及装备前置 |
| 数据去哪 | 本地保存备份、AI 分享和排行榜白名单，不称云存档 |
| 怎样实现测试 | 架构图、源码导航和真实验证入口，不编造 CI 徽章 |
| 如何复用贡献 | 用户选择的保留权利声明、独立第三方说明、贡献与报告渠道 |

不填写未经证实的最低硬件、没有核实发行版的下载按钮、在线服务保证，或用旧验证证明当前代码。更广的指南通过链接访问，历史说明明确标注，避免复制过时描述。

## 社区清单对应

Description 是仓库元数据。README、行为规范、贡献、License 和 Security 在根目录，Issue/PR 模板在 .github。GitHub 默认分支收到这些文件后才更新远端清单。自定义保留权利不是 OSI 开源许可，未必显示标准许可徽章。

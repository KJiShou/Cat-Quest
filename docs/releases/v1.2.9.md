# Cat Quest 1.2.9 for Windows x64

- Improve large-save performance by reducing repeated copying, serialization work and validation-cache compression. Saves remain atomic, with failure/retry protection and backup recovery. Very large histories can still cause a brief pause.
- Speed up Tasks, History and Focus Statistics refreshes and reduce unnecessary work on hidden pages and previews.
- Refine navigation hover shapes and shadows, shared button feedback, reward effects and equipment interactions while preserving the existing layouts and typography.
- Simplify unnecessary explanatory labels and use existing icons and visual states where appropriate.
- Align the Mastery tutorial with the current fixed claim order. Preserve the original Boss result Continue flow.
- Replace technical filesystem paths in save-failure dialogs with a concise retry message.

Existing gameplay, reward amounts and caps, End Early settlement, equipment progression and save compatibility are preserved. The faster save-validation cache uses additional memory proportional to the primary save and backup sizes.

Extract the entire Windows ZIP into a writable folder and run `CatQuest.exe`, keeping all accompanying files together. This release contains a Windows build; the separately hosted browser edition is unchanged.

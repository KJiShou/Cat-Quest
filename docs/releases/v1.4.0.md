# Cat Quest v1.4.0 — Faster SQLite Saves

## What's changed

- Replaced routine whole-JSON saves with background SQLite transactions. Tasks, Focus, equipment, loot and Boss progress update the affected records without rewriting all history.
- Automatically migrate supported existing JSON saves on first launch, validate the imported data and retain the original. Subsequent launches use SQLite as the authoritative save.
- Added consistent `.catquestbackup` export/import for device transfer, local recovery snapshots, schema migration protection and clearer storage failure handling. Legacy JSON import remains supported; credentials and sharing authorization are excluded from portable backups.
- Preserve scrolling and selection through scoped page refreshes, paginate history, and aggregate Focus statistics in the database.
- Refined task notification feedback, task menus and equipment text layout while preserving the authored UI. Improved verification of battle motion, process ownership and graceful shutdown.
- Updated the English/Chinese README with current documentation and eight new 1920×1080 screenshots captured from the application using synthetic data.

## Before updating

Close active Focus sessions and battles, keep a backup, and extract the full Windows ZIP together. The new save is `catquest-data.sqlite3` in the existing save directory. The retained JSON is only the pre-migration snapshot: **downgrading to a JSON-only version will not preserve subsequent progress**. Use Settings backup export when moving to another device; do not copy only a running database's main file.

## Verification and known limits

- 636 storage/migration checks, the domain regression chain, affected UI flows, real process restart/crash handling, Companion and updater/new-player handoff were exercised with isolated data.
- 29 operations × six data combinations × 100 measured samples for both engines: 34,800 measurements. At 1,000 active tasks and 100,000 historical records, per-operation P95 was 33–37 ms for SQLite versus 866–1,226 ms for JSON on the test machine. All SQLite P95 gates passed. These Development-build measurements are not a latency guarantee for every device or every individual save.
- The actual unchanged 1.2.1 executable's end-to-end update route remains unverified because a separate Windows profile/VM was unavailable. The tested updater handoff uses a synthetic legacy fixture and must not be confused with that route. The maintainer authorized publication after disclosure of this gap.
- This release ships Windows only. Current Web source is a session-only SQLite demo; reload starts a new session. The local browser smoke passed, but its Development package exceeds the upload-file size limit. The hosted itch.io version is not updated by this release.
- Existing vendor/demo missing-script references remain documented. Process-kill and injected disk failures do not prove all physical power-loss or full-disk scenarios.

See [the verification report](../../SQLITE_VERIFICATION_REPORT.md) and [storage details](../../SQLITE_STORAGE.md).

## 中文更新说明

- 日常存档改为后台 SQLite 事务，按受影响记录保存，避免历史越来越多时反复复制和重写整个 JSON。
- 旧 JSON 首次启动自动迁移、校验并保留原档；之后启动、保存和恢复以 SQLite 为准。
- 支持 `.catquestbackup` 一致性备份、换设备导入、本地恢复快照和旧 JSON 导入；账号凭据及分享授权不随备份转移。
- 页面局部刷新保留滚动与选择状态，历史分页读取，Focus 统计使用数据库聚合。
- 改善任务通知、菜单和装备文字布局，保留手工 UI；补齐战斗动画、进程独占和关闭等待检查。
- 更新中英文 README，并使用演示数据重新拍摄八张 1920×1080 实际画面。

**升级提醒：** 请先结束 Focus／战斗并保留备份。旧 JSON 只代表迁移前进度，旧版本无法读取之后的 SQLite 进度；换设备请使用设置中的备份导出。

**验证范围：** 636 项存储／迁移检查及业务、UI、Windows 验证已执行；34,800 次性能测量完成。本机最大数据组合的各项 P95 从 JSON 866–1,226 ms 降至 SQLite 33–37 ms。真实 1.2.1 可执行文件的完整更新路线仍因缺少隔离环境而未实测，不能把模拟旧档的更新交接当作该项已通过。维护者已在获知此限制后授权发布。本次不发布 Web 构建，也不宣称验证了所有硬件断电情况。

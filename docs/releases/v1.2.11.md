# Cat Quest 1.2.11 for Windows x64

- Add the Equipment Shop with 18 chest items, single and ten draws using Boss Tickets, animated reveals, rarity information and duplicate Fish Coin conversion.
- Add six Legendary equipment abilities: bonus health, attack speed, critical hits, full-hit blocking, defence piercing and every-fifth-hit burst damage.
- Increase normal Boss combat stats to support the expanded equipment progression; unlock conditions and Master Stage scaling remain unchanged.
- Make Auto Select consider equipped abilities, Boss set bonuses and the next available Boss encounter. Keep the displayed Power score as the existing stat summary.
- Add weapon-specific fist and staff presentation in Boss battles, Focus training and the Pet Widget, with critical-hit and block feedback.
- Show a green ownership check on Equipment List cards, improve inventory scrolling and equipment details, and remove the extra independent-draws footer.
- Let the cat wait for the Boss to fall before running away after an ordinary victory. Skip remains immediate.

Existing task and Focus reward rules, Boss entry costs, mastery sets and progression are preserved. Saves upgrade to version 6 without resetting progress; the first successful upgrade preserves the original save in a `.before-shop.bak` backup. Older app versions cannot open the upgraded save.

Extract the entire Windows ZIP into a writable folder and run `CatQuest.exe`, keeping all accompanying files together. The separately hosted browser edition is unchanged.

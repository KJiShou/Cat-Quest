## Maintenance rules

1. Update both editions together, preserving the same rules, boundaries, numbers, verifier entrypoints and historical limitations. The Chinese edition is not a summary-only replacement.
2. Ordinary documentation links should remain in the reader's language. Language selectors intentionally cross languages. Images and source paths are shared.
3. Do not use ASCII or full-width semicolons in maintained Markdown. Split sentences or use new lines without breaking executable commands.
4. Retain established English paths, especially AGENTS.md, .impeccable.md, README.md and GitHub default files, for tool discovery. The Chinese PR template can be opened through its language link and copied. GitHub still loads the English default automatically.
5. Preserve explicit historical labels on review/audio-design records. Old reports are not current verification. Check code before correcting a documented rule, without changing gameplay to match documentation.
6. Keep raw screenshots/test outputs ignored and curated README images under docs/images. Translation does not require new UI authoring or captures.

## Original-language exceptions

Assets/Spine/CHANGELOG.md and Assets/Spine/Runtime/spine-unity/Shaders/Sprite/README.md belong to third-party packages and retain their original language and punctuation. Third-party licenses/source notices remain unchanged. Library, Temp, Builds, Logs, obj, package caches and generated directories are outside the maintained documentation set.

The root LICENSE is not Markdown. It remains the formal English reserved-rights notice, with a Chinese explanation in the licensing guide instead of a competing legal text. Translation does not change vendor terms.

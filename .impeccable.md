## Design Context

### Users
Cat Quest users working at a Windows 10/11 desk who need a glanceable focus timer and playful companion while another application has their attention. The current task is a redesign of this companion, not the main dashboard.

### Brand Personality
Playful, friendly, calm. Preserve Layer Lab GUI Pro-SimpleCasual artwork, font and the ninja training with Acorn.

### Aesthetic Direction
User supplied a title-bar reference for layout only, explicitly rejecting a black bar. Use a light SimpleCasual header, centered player name and only the source-popup circular close control, true rounded Windows region and UI mask, full game view below it, timer on the sky, one session action on the water. No other information or hover tooltips.

### Design Principles
1. Animation fills the available content area; timer is the only persistent content overlay.
2. Session buttons fade in on pointer enter and fade out on exit at every size, without changing scene layout.
3. Four-edge and four-corner resizing with standard cursors; no dedicated lower-right grip.
4. Keep window controls separate; closing does not stop Focus.
5. Preserve the authoritative main timer, state-driven animation and rewards.

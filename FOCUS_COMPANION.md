# Focus page and Windows companion

Open `Assets/Scenes/CharacterHome.unity` and select Focus. Choose Pomodoro (default), Stopwatch or Countdown. Stopwatch counts up until End Focus, including beyond three hours; Countdown accepts 1–180 whole minutes (default 25) and finishes automatically. Only Pomodoro enters Rest. Choose Focus and Rest durations with whole-minute sliders (each 1–60 minutes, defaults 25/5), and one optional tag from the Tasks tag catalog. Start Focus is inside the lake training view. Pomodoro exposes only Cancel while focusing, with a confirmation before discarding the session; it grants no rewards and does not start Rest. Normal Pomodoro completion still settles rewards and starts Rest. Stopwatch End Focus and Countdown End Focus Early retain their existing settlement rules. Tags are optional and do not affect rewards or complete tasks.

The training scene fills the main Focus background with rounded clipping. The page heading and Return to Dashboard button are hidden; use the shared sidebar to navigate. Focus and Rest each have a floating white duration card, shown according to mode. The sky shows the timer. The tags field opens a dropdown and filters tags by name as you type (case-insensitive); choosing a tag replaces the previous selection and closes the list; No tags clears the selection for free focus. Clicking outside or pressing Escape closes the dropdown. Reward tiles reuse the blue Fish/EXP boxes from Task Details, plus a matching Boss Ticket tile, with numeric previews and settled session values. The allowance card shows daily usage and session/daily reward-limit messages.

Enable Pet Widget to open a 420×300 always-on-top companion. The rounded window uses a light title bar with the player name centered and Pin, Minimize and Close buttons. Close is copied from SimpleCasual Lobby_Popup_User_Info; Pin/Unpin and Minimize use Lucide icons (license in Assets/Generated/Icons/WindowControls). Pin toggles always-on-top and remains unchanged when resizing. Minimize exposes a taskbar button for restoration without ending the Focus session. The name is published by the main program; the companion does not read the player save. Both the Unity UI mask and native Windows window region have 16-pixel rounded corners, refreshed when resized. The game view fills all space below the bar; the timer overlays the sky and the current session action overlays the water. No quest, reward, preset details or hover tooltips are shown.

At every size, the session action stays hidden while the pointer is outside. Entering the window fades the action in over roughly 0.32 seconds; leaving fades it out over roughly 0.24 seconds. Start, Cancel (Pomodoro), End Focus / End Focus Early (other modes), Finish Rest and Retry Save use the same fade behavior. Animation framing stays fixed during the transition. Use the title bar to move the window, or any of its four edges/eight edge-and-corner hit regions to resize with standard Windows sizing cursors (minimum 240×180). Close hides the native window immediately, then exits the companion process while Unity cleans up. Focus remains running in the main app.

## Authoring and build

Focus and Rest sliders reuse the Quantity row from SimpleCasual Light/Material_Level_Up, including its blue fill, triangle markers and cyan plus/minus artwork. Drag or click the bar to choose whole minutes; plus/minus changes one minute and disables at the selected mode's boundaries. The serialized mode selector presents three side-by-side icon cards adapted from SimpleCasual `Btn_MenuButton_Rectangle01_Light` in `Btn_MenuButton_Rectangle01-Group.prefab`. It keeps the existing exclusive Toggle group and native hover/press/keyboard transitions, with project typography and a blue underline for the selected mode. Circular-arrow, stopwatch and hourglass icons accompany Pomodoro (Focus + rest), Stopwatch (Count up) and Countdown (Count down). Stopwatch hides duration cards; Countdown hides Rest. Settings lock after Focus starts. Modify existing serialized controls directly; do not regenerate the page.

- Whole-page and companion builders are legacy creation tools; do not run them to modify existing authored UI.
- Build Windows x64 with the enabled scenes, starting with CatQuestBootstrap, then IntroStory and CharacterHome. The companion is launched from the same executable with a separate startup argument; distribute the entire Windows build folder together.
- The generated executable is `Builds/Windows/CatQuest.exe`. Editor Pet Widget previews use that build, with the Editor remaining the session authority.

## State and persistence

FocusController is the only live timer owner. FocusSessionOptions carries mode, selected durations and optional tags (legacy quest context remains compatible). Mode zero is Pomodoro for old saves. New receipts record actual elapsedSeconds separately from reward-eligible seconds; Stopwatch may exceed the per-session reward limit. New non-Pomodoro modes have zero Rest duration, and Stopwatch has zero target duration. Existing daily usage and historical rewards are preserved; no rewards are backfilled. FocusSession receipts additionally store selected durations and tag ID/name snapshots; old quest title/occurrence snapshots remain intact. Legacy receipts normalize missing durations to 25/5; existing balances are unchanged.

CompanionHost publishes an atomic companion-session.json with a heartbeat in a unique temporary directory per main process. Companion commands carry the owner, session and unique request ID; the host rejects stale and duplicate requests. The companion never creates GameDataManager or writes player saves. After three seconds without a heartbeat it freezes its last timer display, disables session controls and switches training to Idle.

Main-page and companion animation use the same display-only IFocusPresentation interface. Each new Focus session snapshots the Cat Level when it starts. Its multiplier is `1 + 0.1 * (level - 1)`: multiply the base 1 EXP per full eligible minute and 2 Fish Coins per full 5 eligible minutes, then floor each final amount. Reward time stays fixed at 180 minutes per session and 360 minutes per day. Only the reward amounts scale. At Lv.30 this means 97 EXP / 39 Fish per 25 minutes, session ceilings of 702 EXP / 280 Fish, and daily ceilings of 1404 EXP / 561 Fish (per-session flooring can pay slightly less). The session snapshot fixes its multiplier through mid-session level-ups and save retries; the next session uses the new level. Daily usage remains measured in minutes, shared across modes and attributed to the settlement day. End Early uses the same rules and contributes actual eligible seconds to the daily goal. Boss Tickets remain one per full 25 eligible minutes, at most 4 per day, without a level multiplier. Pomodoro/Countdown duration selectors retain their existing 60/180-minute maxima; Stopwatch can continue beyond the fixed reward allowance without further EXP/Fish. Capped sessions remain usable. After successful settlement, Pomodoro enters Rest and other modes finish directly; failed saves remain retryable without duplicate rewards. Rest, Cancel and invalid/interrupted sessions grant nothing. OS sleep or a gap greater than ten seconds invalidates an unverifiable active session. Historical receipts are not repriced: missing rewardLevel uses the original level-one rules. Decorative fish are capped at the original 72 instances; this never caps Fish Coins.

### Companion shutdown cleanup

Windows companions are launched with `-force-d3d11`. On the current Unity 6000.3.10f1 build, D3D12Core.dll crashes with 0xc0000005 during tool-window shutdown; D3D11 exits normally. This argument applies only to the child process, not the main application's graphics settings.

`SpriteSkinShutdown` registers the 2D Animation 13.0.4 fallback-buffer cleanup on `Application.quitting`. The package allocates a static ComputeBuffer after scene load even without SpriteSkin instances, but only releases it through deformation-system cleanup. Our sprite-sequence companion does not create that owner. The workaround calls the package's existing idempotent `ClearFallbackBuffer` method; `Assets/Scripts/UI/link.xml` preserves that internal method in stripped builds. Recheck and remove the workaround when upgrading to a package that cleans up the fallback buffer itself.

## Focus insights

Open **Focus insights** from the Focus page. Day shows hourly bars, Week uses Monday�Sunday, Month uses calendar days, and Year uses months. Previous/next and Today navigate calendar periods; future periods are disabled. All tags are shown together as colour-coded stacked bars by default, with matching Time by tag legend swatches. Duplicate catalog colours receive distinct display colours without changing the saved tag colours; colour assignments use the full catalog/history and remain consistent across periods. Hover/tap a coloured segment for its tag and duration. Clicking a legend row optionally isolates one tag; All focus restores the stacked comparison. Back to Focus or Escape closes the view; changing pages also closes it.

Only committed Completed and EndedEarly receipts contribute. The view uses actual elapsedSeconds (including time beyond reward caps), falling back to legacy eligibleSeconds/minutes only if actual time is absent. Intervals end at completedUtc and extend backwards by the recorded active duration; overlaps are split across local-time hours/days/months. Totals are not rewards and never write or reprice receipts. Running, cancelled, interrupted/invalid and Rest time are excluded. Sessions touching a period are counted once there. Exact seconds are aggregated before the duration label rounds down to whole minutes; sub-minute results display <1 min.

Each new Focus session accepts at most one distinct tag. Old untagged receipts appear under No tag. Tag IDs own grouping, current catalog names/colors are used when available, and deleted tags retain their saved names. Historical multi-tag receipts remain intact and count under their original tags; tag totals overlap while All focus counts each receipt once. The About this data button and explanation area have been removed; the chart and tag list use the freed space. Today is blue while viewing the current period and pale blue while viewing another period.

Authored UI: Assets/Prefabs/Focus/FocusStatistics.prefab, nested additively under the existing Focus page. Runtime: FocusStatistics (pure receipt query), FocusStatisticsUI (display/input), FocusStatisticsGraph (batched grid/bar mesh).

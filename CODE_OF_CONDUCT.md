# Code of Conduct

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

Cat Quest welcomes respectful participation in its issues, pull requests and project discussions, regardless of experience, background or identity.

## Expected behavior

- Be constructive, patient and specific. Discuss the code or idea without attacking the person.
- Respect differing perspectives, time constraints and the project's student scope.
- Ask before sharing someone else's personal information, screenshots or work.
- Give credit and respect the rights attached to code and creative assets.

Harassment, threats, discriminatory abuse, unwanted sexual content, impersonation, deliberate disruption and publishing private information are not acceptable.

## Reporting and enforcement

The maintainer, [KJiShou](https://github.com/KJiShou), is responsible for moderation. For visible conduct problems, reference the offending comment in a concise moderation request without repeating abusive or private content. Use GitHub's **Report content** tools for platform abuse. If a report needs a private conversation, request a private contact channel without posting the sensitive details publicly.

The maintainer may ask for a correction, remove or edit inappropriate content, close disruptive discussions or restrict participation, proportionate to the conduct and its impact. Threats, harassment or repeated abuse can result in immediate restrictions. Anyone affected may request reconsideration with relevant context through the same reporting route.

This policy applies to project spaces and to interactions where someone explicitly represents this project. Good-faith technical disagreement and respectful bug reports are welcome.

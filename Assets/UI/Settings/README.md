# Google sign-in artwork

`GoogleSignIn.png` is the unmodified, pre-approved light pill sign-in button
from Google's Android + Web PNG @4x bundle. The complete image preserves the
Google mark, button proportions, caption, and Google Sans typography. It is an
intentional branding exception within the project's Fredoka/SimpleCasual UI.

Source: https://developers.google.com/static/identity/images/signin-assets.zip

Usage guidelines: https://developers.google.com/identity/branding-guidelines

Retrieved 2026-10-21. Google trademarks remain Google's property.
